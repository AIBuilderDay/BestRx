AI agent → cart hand-off — three options

Deciding: what the nurse sees between "the agent understood me" and "the item is in my cart". Pairs with mockups/enhanced-search.html, which decided the bar (Search / ✦ AI switch) and the thinking animation (Ocean sweep, blues only). Each option below plays the full sequence — typing, ~2.5s of agent thinking, then the drawer auto-opens with the agent-added item highlighted among existing items. Hit Run the sequence under each frame; flip the theme and run it again.

Option A Recommended
Wave hand-off — the light leaves the bar and arrives at the drawer
When the agent finishes, the ocean-sweep glow dies in the search bar and the same flowing blue gradient runs down the drawer's left edge for ~1.5s — one light, handed from the bar to the cart. The new line item slides in from the top with a blue wash that fades over ~2s, and a small "✦ Added by AI" chip stays for auditability. Recommended because it reuses exactly one already-decided visual (the wave) at drawer scale — a continuous, quiet hand-off that reads premium, while B floods the whole panel and C animates a literal projectile.
typing → ocean-sweep thinking → drawer edge lights up → item slides in with the blue wash.
Option B
Ocean flood — the drawer opens on a wave
The cart icon pulses a blue ring as the count ticks up, the drawer slides open, and a soft aurora halo washes down the whole panel (~1.2s, then gone). The new item scales in wearing the flowing gradient as its border ring for ~3s before settling to a normal border; the "✦ Added by AI" chip stays. The loudest of the three — great demo energy, but the full-panel wash touches items the agent didn't add.
typing → thinking → cart icon pulses + count ticks → drawer floods → item scales in with a gradient ring.
Option C
Comet — the item visibly travels from the bar to the cart
A glowing blue comet arcs from the search bar to the cart icon, the icon flashes and the count ticks up, then the drawer opens and the item drops in with the blue wash and chip. The most literal "your order traveled to the cart" — instantly legible for a brand-new user, but the projectile is the most gimmicky of the three and competes with the drawer for attention.
typing → thinking → comet arcs to the cart → icon flashes + count ticks → drawer opens, item drops in.
