BestRx design system

Deliberately basic, and meant to be edited. Lifted from mockups/orders-board.html and mockups/cost-ledger.html so every screen looks like the same product on day one.

Token source of truth for the app: frontend/src/styles/tokens.css, imported by frontend/src/index.css. Keep this file's values in sync when you change the palette.

Anyone can change this as we go. It is a starting point, not a rulebook. The only rule: change it here and in index.css, rather than working around it inside one component. Token or pattern changes affect everyone's screens, so keep them in a small standalone PR instead of burying them in a feature.

The look, in one sentence

Near-monochrome, thin borders, generous whitespace, tabular numbers, colour used only where it carries meaning. Shop-app interaction patterns, clinical restraint in tone.

Brand — the capsule logo

 This is the one BestRx mark, everywhere — app chrome, login, mockups, docs, favicons. Never hand-roll another wordmark, dot, or icon. In the app, render <Logo /> from frontend/src/components/ui/Logo.tsx — the capsule fills with currentColor and the wordmark knocks out to --bg, so it inherits any surface and theme. Static copies live in frontend/public/images/brand/ (bestrx-logo.svg, and bestrx-mark.svg — the "b" pill used as the favicon). The reference sheet, with inverted and small sizes, is mockups/logo.html.

The three semantic colours

Colour is meaning, never decoration. There are exactly three, each with a background tint for fills. Do not add a fourth — no blue link colour, no separate info palette.

riskA patient-facing failure in progressAn order that will miss its deadline, a breached pickup SLA

If you cannot say which of the three a case is, it probably needs none of them — use ink levels.

The AI accent (blues)

One deliberate exception to "no fourth colour": a blue ramp that means exactly one thing — an AI-powered surface (the enhanced search bar, AI-ranked results, an agent-added cart line). It is never a status colour and never decoration; if a blue appears anywhere AI is not actually involved, it is wrong. The ramp is purple-free by design. Radii and spacing

--radius-control 7px for buttons and inputs, --radius-card 10px for cards and tables, --radius-panel 12px for drawers and modals. Never hardcode a hex value or a pixel radius in a component. If the tokens do not cover it, add a token here first.

Charts

mockups/cost-ledger.html sets the bar. Follow it:

  • Derive everything. No hardcoded totals on screen. Change a period or a filter and the whole view stays coherent.
  • Round axis ticks. Scale to a nice step (1, 1.5, 2, 2.5, 5 × a power of ten), not to max × 1.1.
  • Label the SVG. Every chart carries role="img" and an aria-label stating the shape and endpoints. Hover targets get their own labels and keyboard focus.
  • Small multiples over many charts. Seven sparklines in a table column read faster than seven separate charts.
  • The shaded gap is the point. When comparing two lines, fill the space between them — that area is the money, made visible.

If the dataviz skill is available, load it before building a chart.

Rules

  • Borders over shadows. No drop shadows except on a true overlay.
  • Focus is global. :focus-visible is styled once in index.css. Do not remove or restyle outlines per component.
  • Dark mode is not optional. Use tokens and you get it free. A hardcoded colour breaks it, which is the fastest way to spot one — toggle the theme above.
  • Tables scroll inside their own wrapper, never the page. The wrapper needs overflow-x: auto, and its grid parent needs min-width: 0 or the whole page scrolls sideways on mobile.
  • Build for the device. Field nurses are on a phone browser; admissions nurses and dashboards are desktop. Assume an untrained user — nurse turnover is high.
  • Respect motion preferences. Any transition gets a prefers-reduced-motion escape.
  • Tone. Plain, specific, respectful. No exclamation marks, no celebration, nothing cheerful next to a death or a delayed pickup. A toast explains what happened; it does not congratulate.
